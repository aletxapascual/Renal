# 🌐 Sitio Web + Sistema Interno de Gestión de Productos

Este proyecto es un sitio web informativo con sistema de gestión interna, desarrollado para un negocio con múltiples sucursales. Incluye una página pública (información de marca, productos, contacto) y un panel de administración para la gestión de inventario y ventas.

---

## 🛠️ Tecnologías Utilizadas

- **React** – Frontend moderno y responsivo
- **Firebase Firestore** – Base de datos en tiempo real
- **Firebase Hosting / Vercel** – Despliegue del sitio
- **Tailwind CSS**  Estilizado
- **Context API / Zustand** – Gestión de estado
- **React Router DOM** – Navegación entre secciones

---

## 🚀 Funcionalidades

### Página Pública
- **Inicio**: presentación de la marca y mensaje principal
- **Acerca de**: historia, misión y visión del negocio
- **Productos**:
  - Catálogo con todos los productos disponibles
  - Visualización de **fichas técnicas** por producto
  - **Disponibilidad por sucursal**
- **Contacto**:
  - Formulario funcional
  - Botón directo a WhatsApp

### Panel Administrativo
- Registro, edición y eliminación de productos
- Filtros por sucursal
- Visualización de disponibilidad por punto de venta
- Registro de ventas por mes y por sucursal
- Resumen de ganancias mensuales
